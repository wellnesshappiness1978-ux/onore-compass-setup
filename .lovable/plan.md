# 出生宇宙創生図「円形公転軌道アート」再調整計画

## 目標
太陽を絶対中心に置き、水星から海王星までの**8本の円形公転軌道**を作品の骨格にします。木星・土星などの外惑星が地球より太陽に近く見える誤解をなくし、出生瞬間の惑星配置と公転順序が一目で分かる、気品ある天文アートへ整えます。

## 1. 公転順序が明快な同心円構図
- 太陽を画面中央へ固定し、8軌道を完全な同心円として描きます。
- 軌道半径は常に `水星 < 金星 < 地球 < 火星 < 木星 < 土星 < 天王星 < 海王星` となるよう、惑星ごとの代表的な軌道長半径を共通の対数縮尺で配置します。
- 出生時の太陽からの瞬間距離によって軌道円自体が内外へ揺れないようにし、外惑星が地球軌道より内側に見える現象を防ぎます。
- 各惑星は登録プロフィールから算出した出生瞬間の太陽中心黄経に置き、出生時の角度関係は維持します。

## 2. 円形軌道をアートの主役へ
- 8本の軌道は細い金・白金の光輪を基調に、内外で線の密度と輝度を整えます。
- 地球軌道のみ上品な金色の粒子でわずかに強調し、他軌道も消えずに判別できる均衡へ調整します。
- 星雲、星座、干支、7つのバースカラーは軌道の背後へ抑え、同心円を隠さない一枚絵にします。
- 惑星名、黄経、距離AUは引き出し線で安全領域へ整理し、惑星や軌道と重ねません。

## 3. 惑星と出生地球
- 8惑星の球体サイズは現在の物理半径比と全惑星共通倍率を維持し、土星本体と環の物理比も保ちます。
- 軌道上の地球は他惑星と同じ規則で表示します。
- 出生地点・地球の向き・昼夜境界を示す地球拡大図は、選択どおり**軌道外周へ小さく分離**します。
- 拡大地球には別縮尺の細部図であることを明記し、海王星軌道や惑星との重なりを避けます。

## 4. 誤解のない表示
- 画面内の説明を「角度＝出生瞬間の黄経／軌道順＝実際の公転順／軌道間隔＝代表軌道距離の共通対数縮尺／惑星径＝実半径比の共通拡大」に更新します。
- 各惑星の数値として表示する出生瞬間の実距離AUは維持しますが、軌道半径の決定には使わないことを明確にします。

## 技術詳細
- 惑星データに公転順と代表軌道長半径を持たせ、円形軌道半径をその値から決定します。
- 出生瞬間の計算は黄経、実距離AU、地球自転・出生地表示に使用し、軌道帯の半径とは分離します。
- ライブ表示と2048×2048保存は同じ配置・描画関数を共有します。
- VIP限定、外部通信ゼロ、即時表示、決定的な再生成、全画面・共有機能を維持します。

## 検証
- 複数年代・日時で、8軌道の半径順が常に公転順どおりであることを自動確認します。
- 各惑星の表示角度が出生瞬間の黄経と一致することを確認します。
- 木星・土星を含む全外惑星が、地球軌道より外側に表示されることを確認します。
- PC・スマートフォン・全画面・2048保存で、8本の円形軌道、惑星、ラベル、小さな拡大地球が重ならず読めることを確認します。
