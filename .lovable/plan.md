# 出生宇宙創生図「芸術×天文図」再構築計画

## 結論
一枚の絵の中を、**背景の太陽系全景**と**手前の出生地球拡大図**の二層に分けます。

```text
┌──────────────────────────────┐
│  出生瞬間の太陽系全景                  │
│  太陽を基準に、8惑星を実黄経で配置      │
│             ◉                    │
│       惑星軌道と星雲                    │
│                           ╲          │
│                 地球の軌道位置 ──┐    │
│                                  │    │
│        出生時刻の地球を大きく拡大   ◯   │
│        昼夜境界・出生地点・現地の光     │
└──────────────────────────────┘
```

これにより、「宇宙のどこに地球があり、その地球のどこで生まれたか」を視線の流れだけで理解できる作品にします。

## 1. 背景：出生瞬間の太陽系を正確に見せる
- 太陽を太陽系全景の基準点に置き、地球を含む8惑星を出生日時の太陽中心黄経に沿って配置します。
- 惑星間の角度は実データを保持し、距離だけを画面内で読める対数的な美術表現へ変換します。
- 細い案内線は使わず、半透明の金泥軌道、星屑の密度、光の弧で「実配置図」と分かるようにします。
- 地球の軌道位置だけを総合カラーと金の二重光で強調し、手前の地球拡大図へ一本の柔らかな光流でつなぎます。

## 2. 手前：出生時刻・出生場所が分かる地球拡大図
- 地球は画面下部〜中央の主役として大きく描き、背景の軌道上にある地球を拡大したものだと分かる構図にします。
- 出生時刻から恒星時・地軸・太陽方向を求め、同じ球面上に大陸、雲、昼夜境界、大気光を描きます。
- 鑑賞カメラは出生地が見える最小角度へ調整しつつ、地球そのものの出生時自転と太陽方向は変えません。
- 出生地点は地図ピンや照準器ではなく、地表内部から湧く総合カラーの光核、花弁状の大気光、上空へ立つ微細な星粒で表します。
- 出生地の経緯度、現地子午線、昼側／夜側の関係が、説明を読まなくても見分けられる明暗設計にします。

## 3. 一目で理解できる最小限の情報表示
- 画面外周に「出生日時」「出生地」「出生地点の現地時刻」を小さな金文字で表示します。
- 太陽・地球・各惑星には作品を邪魔しない極小ラベルを置き、全画面時と保存画像でも判別可能にします。
- 「惑星角度は出生瞬間の実配置／軌道距離は鑑賞用に圧縮」という短い注記を下端に入れ、誤解を防ぎます。
- 星座と干支は情報記号にせず、太陽系全景の外周にある黄金・白金の守護レリーフとして背景へ統合します。

## 4. 作品としての統一
- 7色は惑星表面ではなく、総合・健康・恋愛・仕事・金運の順で星雲、輝線、星間塵へ配分します。
- 太陽系全景と地球拡大図に同じ光源、絵具粒度、金粉、色温度、霞を適用し、図解を貼り合わせた印象をなくします。
- 地球は硬いテカリを避け、海洋の深い発光、大気散乱、夜側の微光、薄い雲影で主役化します。
- 惑星は固有模様と球面陰影を保ち、星雲へ溶けすぎず実配置を追える明瞭さを確保します。

## 5. システム仕様の維持
- 曼陀羅はStandard以上、出生宇宙創生図はVIP以上の権限分離を維持します。
- 外部通信を使わず、プロフィールから即時・決定的に描画します。
- 画面、全画面、2048×2048 PNG保存は同一の描画処理とレイヤー順を共有します。
- 出生時刻不明・出生地を特定できない場合は、概算表示であることを作品内に明記します。

## 技術詳細
- 太陽系全景は、各天体の太陽中心黄経を共通の黄道座標へ投影し、角度を保持したまま表示半径だけを美術的に圧縮します。
- 地球拡大図は、恒星時・地軸傾斜・太陽時角・出生地緯度経度・鑑賞カメラを分離して計算します。
- 背景の軌道上の地球と、手前の拡大地球は同じ天体データを参照し、光流で視覚的に対応付けます。
- ラベル、惑星、出生地点光、地球縁が重ならない安全領域を計算し、画面サイズに応じて位置のみ調整します。

## 検証
- 複数年代・時刻で、8惑星の表示角差が出生瞬間の太陽中心黄経差と一致することを自動確認します。
- 東京・沖縄など複数地点で、出生地点、地表、昼夜境界、太陽方向が同一球面上で一致することを確認します。
- PC・スマートフォン・全画面・2048保存で、太陽系全景→軌道上の地球→出生地点の順に自然に視線が流れることを確認します。
- VIP権限、外部通信ゼロ、ライブ表示と保存画像の一致を維持します。
