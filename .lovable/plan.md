# 出生宇宙創生図・最高峰油彩アート刷新計画

## 現状確認
- 現在は `Dashboard.tsx` から `NineStarsPanel` へ「VIP以上か」を1つの真偽値で渡し、曼陀羅と出生宇宙創生図を同時に開閉しています。そのため、指定どおりの「曼陀羅はStandard以上／宇宙創生図はVIP以上」という分離はまだありません。
- 宇宙創生図は、同梱済みの宇宙背景とCanvas描画を合成し、画面と2048×2048 PNGで同じ描画関数を使っています。外部画像サービスへの通信はありません。
- 現在の惑星は単純な放射グラデーション球が中心で、太陽から各惑星へ直線を描く処理があります。表示半径は水星9〜木星34で、指定の2倍化前です。
- 曼陀羅側には、油彩粒子、凹凸、金泥、宝石面、決定的な乱数による手仕事感のある表現があり、宇宙作品へ応用できる技法があります。

## 完成する体験
- **Free**：両作品とも安全な装飾プレビュー。個人の完成作品・保存・共有・全画面はロック。
- **Standard**：バースカラー曼陀羅をフル解放。出生宇宙創生図はプレビューとVIP案内。
- **VIP / Family / Family Premium**：曼陀羅と出生宇宙創生図をフル解放。
- 宇宙創生図は、レーザー状の直線が一切ない深い宇宙空間へ刷新します。8惑星は現在の正確な2倍の半径で描き、各天体の存在感を高めます。
- 7つのバースカラーは薄い差し色ではなく、軌道、惑星オーラ、星雲の主要な発光色として鮮やかに現れます。
- 同じ出生情報と7色から、画面・全画面・保存画像で同一の構図と質感を再現します。

## 1. 会員権限を作品ごとに厳格分離
- `plans.ts` に「曼陀羅アート」と「出生宇宙創生図」の最低プランを明示し、共通のプラン順位判定から利用可否を返します。
- `Dashboard` は現在のプラン自体を `NineStarsPanel` へ渡し、パネル内で選択中の作品ごとにアクセスを判定します。1つの `testUnlocked` で両作品を同時解放する方式は廃止します。
- ロック画像、説明、VIP案内、全画面、保存、共有、算出値の表示を、選択中作品の権限にすべて連動させます。タブを切り替えた直後に前作品の保存関数が残らないよう、キャプチャ状態もリセットします。
- 7言語のロック文言を作品別に整理し、Standard会員には曼陀羅でVIP案内を出さず、宇宙創生図だけにVIP案内を表示します。
- 開発用プラン切替は見た目の確認だけに使い、既存どおり本番会員権限・サーバー側上限・保存権限を書き換えません。

## 2. 宇宙構図と惑星配置の再設計
- 太陽中心から惑星へ伸びる直線描画を完全削除します。放射線の代わりに、途切れ・かすれ・遠近を持つ楕円軌道と星雲の流れで視線を導きます。
- 全惑星の描画半径を既存値の**正確な200%**にします。体積順位「木星＞土星＞天王星＞海王星＞地球＞金星＞火星＞水星」は維持します。
- 2倍化後も欠けないよう、8本の視覚用軌道半径を広げ、天文計算された黄経角度は変えずに配置します。境界余白、土星環を含む外接範囲、隣接惑星の重なりを決定的なレイアウト検査で保証します。
- 実測値は黄経と太陽距離、作品上の軌道半径・質感・光彩は創作表現として型と説明文で引き続き分離します。

## 3. 本格油彩・宝石惑星レンダラー
- 描画を「背景」「星雲と7色光」「軌道」「太陽・惑星」「黄金フィリグリー」「微細ハイライト」の多層構成へ整理し、画面と保存で共有する純粋な描画関数へ分離します。
- 同梱の深宇宙ベースは、漆黒の余白を残した高精細な油彩星雲ベースとして磨き直します。初回表示ではCanvasの即時フォールバックを先に描き、同梱画像の準備後に同じ構図へ重ねるため、外部待機や空白表示を発生させません。
- 単純なベタ塗り球を廃止し、各天体を円形マスク内の多層描画に変更します。決定的な筆致、油彩ナイフ状の稜線、顔料粒子、厚塗りの陰影、縁の反射、局所的な艶を重ね、拡大しても平坦に見えない表面を作ります。
- 太陽は白熱核、黄金・琥珀の厚塗り、炎の隆起を持つ主光源として描きます。各惑星は固有の大気・縞・岩肌を持ちつつ、7色から割り当てたオーラをまとわせます。
- 地球はサファイアの海、エメラルドの陸、結晶面、濃密な大気光、複層オーロラ、海面反射、曲線状キャウティクスを別レイヤーで描き、サイズ順位を壊さず最も目を引く宝石惑星にします。
- 土星環と星座・干支装飾は、暗金の影、中金、金箔ハイライト、細かな凹凸を重ねた立体フィリグリーに変更します。単一の細線やデジタルな均一線にはしません。

## 4. 7バースカラーを濃厚に統合
- 7つのHex値をそのまま主要色として保持し、各色から明部・暗部だけを局所生成します。元色が作品内に確実に現れる構造にします。
- 軌道環は低透明度の細線から、色の芯・外光・顔料のかすれを持つ発光帯へ変更します。星雲には複数色を大きな流れとして重ね、黒い宇宙とのコントラストを保ちながら高彩度で見せます。
- 各惑星のオーラは対応色の内光・外光・微粒子を重ね、従来の10〜25%制限を撤廃します。ただし中心部まで白飛びさせず、天体表面の油彩質感と輪郭が読める明度上限を設けます。
- 色の割当、星雲の位置、筆致、粒子は出生データのseedで固定し、再描画や保存で揺れないようにします。

## 5. 表示速度・保存品質
- 外部API、外部画像URL、実行時生成サービスは使いません。必要な背景素材はアプリへ同梱し、個人情報・7色・生成要求を外へ送りません。
- 画面用は1024角の即時描画、保存用は同一レンダラーを2048角で再実行します。線幅、粒子、油彩凹凸、光彩半径は共通スケールで変換し、見た目の比率を一致させます。
- 背景画像と決定的なテクスチャをキャッシュし、プロフィールや色が変わらない限り不要な再生成を避けます。背景読込失敗時もCanvasだけで完成作品を描ける状態を維持します。

## 6. テストと目視検証
- **権限マトリクス**：Free／Standard／VIP／Family／Family Premiumで、両作品の表示・全画面・保存・共有・案内先を検証します。特にStandardで「曼陀羅のみフル解放」を固定テストにします。
- **描画構造**：8惑星すべてが旧半径の正確な2倍、サイズ順位維持、太陽―惑星直線が0本、全惑星と土星環がキャンバス内、7色すべてが軌道・オーラ・星雲へ入ることをテストします。
- **決定性と出力**：同じ入力で描画命令と画像が安定し、画面版と2048 PNGで惑星角度・色割当・装飾位置が一致することを確認します。
- **視覚QA**：デスクトップ、モバイル、全画面、Freeロック、Standard曼陀羅解放、Standard宇宙ロック、VIP宇宙解放をPlaywrightで撮影します。惑星の欠け・不自然な衝突・文字や操作ボタンの重なり・黒潰れ・白飛び・デジタルな均一線を目視で洗い出し、修正後に再確認します。
- 既存の天文計算テスト、曼陀羅テスト、プランテストも実行し、最後にプレビューの診断ログが正常であることを確認します。
