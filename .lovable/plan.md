# バースカラー曼陀羅をPollinations.ai動的生成へ全面変更

## 目的
現在の端末内SVGドット曼陀羅を、外部APIキーやバックエンドを使わないPollinations.aiの動的画像へ置き換えます。今回の指定を優先し、漆黒の宇宙背景、立体宝石コア、金の光粒を含む世界観へ更新します。

## 実装内容

### 1. 色名とプロンプト生成
- 現在算出済みの「総合カラー＋6つのバースカラー」を、色コードだけでなく日本語の色名も画像側へ渡せる形に整理します。
- 既存8系統の日本語カラー名を、以下のような英語の画材・宝石表現へ決定的に変換します。
  - サンライズコーラル → `vivid ruby coral red`
  - シャンパンローズ → `luminous champagne rose pink`
  - アンバーゴールド → `shining imperial amber gold`
  - 翡翠グリーン → `vivid emerald jade green`
  - ターコイズ → `luminous turquoise blue`
  - 瑠璃ブルー → `deep sapphire lapis blue`
  - アメジスト → `royal amethyst purple`
  - モーヴピンク → `glowing rose quartz mauve pink`
- 指定文を基礎に、総合カラーを宝石核、残る6色を放射パターンとして組み込む英語プロンプトを生成し、`encodeURIComponent` で安全にURL化します。
- 色の取り違えを避けるため、英語キーワードと実際のカラーコードを対にしてプロンプトへ含めます。

### 2. 一貫した生成と再生成
- 氏名や出生情報、会員IDそのものは外部サービスへ送信しません。
- 現在の7色から決定的な数値ハッシュを作り、初回表示の `seed` に使用します。同じ7色なら同じ作品URLになります。
- 「波動を再調和する（再生成）」では再生成回数をseedへ加え、毎回別作品を取得します。
- 生成URLは指定どおり1024×1024、ロゴなしで構築します。

### 3. 表示、待機、失敗時の扱い
- 曼陀羅表示部を外部生成画像に全面置換し、読み込み中は漆黒背景、幻想的なスピナー、指定の生成中メッセージを表示します。
- 読み込み完了後は画像を全域へフェードインし、既存の全画面鑑賞でも同じ作品を表示します。
- 通信失敗時は待機表示を終了し、安全なエラーメッセージと再試行操作を表示します。自動で無制限再試行はしません。
- 再生成中も直前画像を誤って保存しないよう、保存・共有を一時的に無効化します。

### 4. 保存、共有、操作ボタン
- 画像をBlobとして取得し、既存の保存・共有経路へ渡します。
- 下部操作を「高画質壁紙を保存（ダウンロード）」「波動を再調和する（再生成）」が明確に並ぶ形へ更新します。
- 既存の端末共有、全画面鑑賞、VIPプレビュー制御は維持します。
- 外部サービス側が画像取得を拒否した場合は、保存失敗を明示し、壊れたファイルを作りません。

### 5. 7言語と既存説明の整合
- 生成中、再生成、保存、失敗、画像説明を既存の7言語辞書へ追加します。
- 作品説明をAI生成版の内容へ更新し、「色と光は創作表現」という注意書きを保持します。
- 曼陀羅と宇宙創生図を分離していた旧ルールは、今回の明示的な選択に合わせて置き換えます。

## 技術詳細
- Pollinations.aiはブラウザから直接呼び、秘密鍵・新規バックエンド・データベース変更は追加しません。
- 画像コンポーネントは、URL生成、Blob取得、`onLoad`/`onError`、フェード表示、capture登録と解除を管理します。
- 生成ロジックは純粋関数に分離し、色名変換、seedの決定性、URLエンコード、再生成差分を自動テストします。

## 確認
- 初回生成、ローディング、フェードイン、再生成、壁紙保存、共有、全画面表示を実画像で確認します。
- PC・スマホ幅、通信失敗、再生成中、モーション軽減設定を確認します。
- 外部サービスが利用不能または画像取得を拒否した場合は、その事実を確認結果として報告し、別サービスへ勝手に切り替えません。
