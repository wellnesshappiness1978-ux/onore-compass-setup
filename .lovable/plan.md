# 今日の占い 10機能の再編・項目別通知・白テーマの読みやすさ

## 目標
「今日の占い」を指定の10機能・指定順に並べ替え、プランごとに開放します。各カードの一番下に、毎日の通知をON/OFFと時刻で決められるスイッチを付けます。白系テーマでは文字を読みやすくし、ホームの分析手法一覧に風水環境学を加えます。

## 実施内容
1. **白テーマの読みやすさ**：白系テーマのときだけ、文字が載るカード・詳細画面・枠の背景を不透明に近い白（85〜95%）にし、細い影を付けます。文字は濃紺と濃い金色にして、背景の柄が透けて見えないようにします。暗いテーマの見た目は変えません。
2. **風水環境学の追加**：ホームの「主要な分析手法と役割」に「風水環境学（気の流れと空間調整）」を追加します。7言語に対応します。説明文は環境心理と象徴の観点で書き、効果を約束する言い方にはしません。
3. **今日の占い 10機能（この順に表示）**
   1. 今日の具体的決断（攻める／守る）：無料から
   2. 本日の3ラッキー（色・言葉・料理3品以上）：無料から
   3. 吉方位：無料から。生まれ持った方位タイプと今年の方位はファミリーから
   4. 買い物ガイド：スタンダードから
   5. 健康アドバイス：スタンダードから
   6. クイック対人ガイド：VIPから（今はスタンダードから使えますが、VIPからに変わります）
   7. 今月の3ラッキー（花と花言葉・選んだ理由、行動と目標、お守りアイテム）：ファミリーから
   8. 地球暦の円盤カレンダーと詳細：スタンダードから
   9. 365日の個人バイオリズム（グラフと数値）：VIPから
   10. ファミリーの365日ロードマップとバイオリズム：ファミリーから
   - まだ開放されていないカードは、内容の一部を見本としてぼかして見せ、鍵マークと案内を表示します。料金や会員の判定は変えません。
   - 新しい文章は、生年月日と今日の暦から毎回同じ結果が出る参考値です。健康は普段の心がけの提案にとどめ、医療的な判断はしません。
4. **項目ごとの毎日通知**：10枚すべてのカードの一番下に、ベル・ON/OFFスイッチ・時刻の選択（例 07:00）を同じデザインで置きます。設定はこの端末に保存します。
   - **制限**：今のアプリでは、通知はアプリかブラウザのタブを開いている間だけ届きます（今の通知機能と同じです）。アプリを閉じていても届くプッシュ通知には、別の通知サービスとの接続が必要です。画面でもこの点を正直に案内します。

## 変えないもの
「はじめに」の文章、「あなたの特性」の流れ（キャッチフレーズ → 本質 → 分類別 → まとめ）、否定表現を使わないこと、1画面のアプリデザイン選択、2048×2048の画像保存、スマホの5タブ。

## 技術メモ
- `plans.ts` に今日の占い用の機能と必要プランの一覧を加え、`DailyLifeGuide`/`DayCompass` の並び順とプラン制限をそこから決めます。
- 通知は既存の、アプリを開いている間に動く仕組みを項目ごとに広げます。保存キーは項目ごとに分け、時刻ごとに重複して通知しないようにします。
- 白テーマ用の見た目は `styles.css` の、テーマを切り替えるためのクラスに限定して追加します。
