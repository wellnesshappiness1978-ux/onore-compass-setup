# 出生時の太陽系概念図への変更計画

## 目標
現在の幻想的な宇宙画を、**太陽を中心に8惑星の関係が一目で分かる太陽系概念図**へ変更します。惑星の位置は固定見本ではなく、登録プロフィールの生年月日・出生時刻から算出した出生瞬間の配置を毎回反映します。

## 1. 太陽系概念図の構成
- 太陽を画面中央へ固定し、水星から海王星までの軌道を同心状の8本の軌道帯として整理します。
- 各惑星は、自身の軌道帯上に出生瞬間の太陽中心黄経どおりの角度で配置します。
- 惑星同士が重なる場合も角度は動かさず、名称と数値だけを引き出し線で読みやすい位置へ逃がします。
- 内惑星も判別できるよう、軌道間隔は実距離順を保った共通の対数縮尺で表示します。

## 2. 登録ユーザーの出生データ連動
- 登録済みの生年月日・出生時刻を、現在の天文計算へそのまま使用します。
- 出生時刻不明の場合は、既存どおり日本時間正午の参考配置として明記します。
- 各惑星に名称、出生時の太陽中心黄経、太陽からの距離AUを表示します。
- 日時やプロフィールを変更すると、8惑星の位置と地球表示も同じ計算結果から更新します。

## 3. 大きさと正確さの見せ方
- 惑星本体は物理的な平均半径比を保持し、全惑星に一つの共通表示倍率だけを適用します。
- 土星は球体と環を別々の物理比で描き、横長に変形させません。
- 太陽、惑星径、軌道間隔を完全な同一縮尺にすると惑星が見えなくなるため、画面内に「位置角＝出生瞬間の計算値／軌道間隔＝共通対数縮尺／惑星径＝実半径比の共通拡大」と明記します。
- 「実寸模型」ではなく、実データを読みやすく可視化した概念図であることを誤解なく示します。

## 4. 出生地球と作品性
- 軌道上の地球は他惑星と同じルールで配置します。
- 出生地・自転・昼夜境界を確認できる地球拡大図は、概念図を邪魔しない外周の細部図として残します。
- 出生地点は総合カラーの光で示し、軌道上の地球との対応だけを細い光流で結びます。
- 星雲、7つのバースカラー、星座、干支は背景へ抑え、軌道と惑星配置を最優先にします。

## 技術詳細
- 現在の出生瞬間の太陽中心3Dベクトル、黄経、距離AU、物理半径、地球向きの計算は維持します。
- 描画を「実軌道の立体投影」から「惑星ごとの概念軌道帯＋出生時黄経による配置」へ切り替えます。
- ライブ表示と2048×2048保存は同じ配置計算と描画関数を共有します。
- VIP限定、外部通信ゼロ、即時表示、決定的な再生成、全画面・共有機能を維持します。

## 検証
- 複数の生年月日・時刻で、全惑星の表示角度が計算済み黄経と一致することを自動確認します。
- 惑星の距離順、実半径比、土星本体と環の比率が崩れないことを確認します。
- 出生地球の向き、出生地点、昼夜境界が登録プロフィールと一致することを確認します。
- PC・スマートフォン・全画面・2048保存で、軌道・惑星・ラベルが重ならず読み取れることを確認します。
