# 出生宇宙創生図・太陽中心マスターピース更新計画

## 目標
現在の深宇宙の質感と8惑星の個性を土台に、構図を「中央の太陽を核に、出生瞬間の8惑星が取り巻く一枚絵」へ再設計します。地球は手前側の主役として、登録された出生日時・出生地から求める自転の向きを反映し、作品全体は図解ではなく、光・星雲・天体・星座・干支が連続する幻想的写実画として仕上げます。

## 1. 太陽中心の立体的な構図
- 太陽を画面中央へ配置し、単純な黄色い円ではなく、対流粒・プロミネンス・コロナ・多層の光芒を持つ神聖な光源として新規制作します。
- 8惑星は出生時の太陽中心黄経を保ちながら、円周上の均等配置ではなく、奥行き・大小・重なりを持つ立体的な軌道空間へ配置します。
- 地球は太陽より手前側の前景に置き、太陽と視線を結ぶ主焦点にします。木星・土星を中景の副焦点、外惑星を遠景として、太陽系全体が一つの大きな流れに見える構図にします。
- 軌道は説明線に戻さず、星屑・淡い光の弧・星雲の流れとして必要最小限に示します。

## 2. 出生時の地球の向きを実データ連動
- 宇宙画へ登録済みの出生地・市区町村を渡し、既存の国内代表座標データと出生日時から地球の自転角を計算します。
- 地球は「太陽を中心に見た構図の手前側」に置いたまま、出生地が見える半球を基準に、出生瞬間の昼夜境界と太陽光の方向が整合する向きで描きます。
- 固定画像の単純回転ではなく、同梱した地表・雲・夜景・海洋の素材を球面へ投影し、サファイアの海、エメラルドの大地、雲海、大気縁光、夜側の微光、オーロラを同じ球体上で合成します。
- 出生時刻不明または出生地を解決できない場合は、既存ルールどおり日本時間正午と都道府県代表点による参考向きを使い、虚偽の精密さを出しません。

## 3. 全惑星の比率と形状を修正
- 現在の描画で土星などが横方向に潰れる原因となる、惑星本体と環を一枚の横長画像として同じ高さへ押し込む処理を分離します。
- 土星本体は常に真円の球体比率を保ち、環だけを独立した楕円レイヤーとして前後に分け、半透明の氷粒・影・逆光を描きます。
- 残る7惑星も元素材の縦横比に依存せず、球体本体の直径を基準に描画します。輪郭、表面、陰影、大気、固有オーラを別レイヤー化し、平板化や引き伸ばしを防ぎます。
- 8惑星の識別性と体積順位は維持しつつ、前景・中景・遠景で見た目の大きさを調整し、全惑星が太陽の周囲に自然に存在するよう衝突回避を行います。

## 4. 5つの主役バースカラー星雲
- 7色の正確なカラーコードは加工せず保持し、主役を **総合 → 健康 → 恋愛 → 仕事 → 金運** の順に再マッピングします。
- 総合色は地球と太陽をつなぐ最大の輝線星雲、健康色は地球を包む生命的な光、恋愛色は柔らかな双曲線状の星雲、仕事色は上昇する光芒、金運色は金砂のような星雲粒子として、役割と強度を明確に差別化します。
- 5色は帯やベタ塗りにせず、濃淡のある星雲、透過する輝線、微細な結晶光、局所的な煌めきとして背景と天体の間を流れます。
- サブ色と内面色は、選択どおり遠景の薄い星雲の余韻に限定し、5つの主役色を邪魔しない強度に抑えます。

## 5. 星座と干支を一枚の作品へ統合
- 登録ユーザーの太陽星座を、背景の恒星配置と星間塵が形づくる大きな星座として表現します。細い線画を載せるのではなく、星雲の密度と星の輝度で自然に発見できる構成にします。
- 干支は別パーツの輪郭画ではなく、星雲の陰影、金色の星屑、微かな光の面で形成される守護像として背景へ融合します。
- 星座と干支は互いに競合させず、太陽・地球・惑星の視認性を守るマスクと遠近処理を適用します。全体を同じ光源、同じ色温度、同じ粒子密度で統一し、貼り付け感をなくします。
- 月星座は主役の太陽星座を邪魔しない、ごく淡い遠景の星群として残します。

## 6. 描画・品質・既存条件
- 天文学計算と地球自転計算は端末内の純粋関数にまとめ、同じプロフィールから常に同じ作品を再現します。
- 背景、太陽、8惑星、地球球面、星雲、星座、干支を、画面表示と2048×2048 PNG保存で共通の描画器から合成します。
- 外部画像生成・外部通信・従量課金は追加せず、同梱素材とローカル描画のみを使います。VIP権限、全画面、端末保存・共有も維持します。

## 検証
- 自動テストで、出生日時・出生地による地球自転角、太陽中心配置、8惑星黄経、土星本体の真円比率、7色の保持と5色優先順、同一入力の決定性を確認します。
- 実画面と2048保存画像を目視し、太陽が中心、地球が手前の主役、土星などが変形しない、5色星雲の優先順位が読める、星座・干支が背景へ一体化していることを確認します。
- PC・スマートフォン・全画面で重要天体が切れず、黒い矩形、素材の縁、過剰な線、UIとの重なりがない状態まで修正を反復します。
