# 目的・目標設定／診断対象切替／グループ管理／視認性向上

## 1. 本日のラッキーカラーの読みやすさ
- 色見本の上の文字すべてに、濃い縁取りと影を付けます。明るい色でも暗い色でもはっきり読めるようにします。

## 2. 設定タブ：「目的・目標」と「メイン診断対象」
- 新しいカードを追加します。
  - 目的・目標：選択肢（仕事・恋愛・家族・健康・お金・自己成長）と自由記入欄
  - 診断対象：本人／登録ファミリー（人を選ぶ）／登録グループ（グループを選ぶ）
- 設定は変更するまで保存されます。ログイン中はアカウントに、ゲストは端末に保存します。
- 各画面の連動：
  - 特性タブの見出し：「あなたの特性＆個別診断」／「○○さんの特性＆個別診断」／「○○グループの特性＆グループ診断」
  - キャッチフレーズ・6つの視点・15占術・多層総合診断：選んだ人の生年月日で作り直します。グループの場合はメンバーの共通点と相性、集団としての傾向を表示します。多層総合診断には、目的を達成するためのアイデア・助言・注意点を加えます。
  - 7つのバースカラー：グループの場合は、メンバーの色を合わせた「グループカラー」を追加します。
  - 今日の占い：バイオリズムと当日詳細を、選んだ対象で計算します。グループの場合はメンバーの平均です。
  - AI相談室：選んだ目的と対象を前提に回答します。
  - アート：常にご本人だけが対象です。ファミリーやグループを選んでいる間は、ご案内の表示に切り替えます。
- 登録されていない情報（出生時間など）は推測で埋めません。「算出していません」と表示します。

## 3. ファミリータブ：登録・編集
- 「ファミリー登録・編集」と「グループ登録・編集」の2つのボタンを並べます。どちらも画面上に開く入力窓で操作します。
- ニックネームを追加します。ニックネームがあれば優先して表示します。未入力のときは、ファミリーは氏名、グループは「グループA」「グループB」…と自動で名付けます。
- 各カードは、その人やグループの総合バースカラーを背景や差し色に使います。名前は大きめの縁取り文字で表示します。

## 4. プラン別のグループ登録数
- 無料0・スタンダード1・VIP3・ファミリー10・ファミリープレミアム30
- 上限を超えて登録しようとすると、上のプランのご案内を表示します。サーバー側でも同じ上限を守ります。
- プランカードの「具体的なメリットと使い方」欄に、グループ登録数とできることを7言語で書き加えます。

## 5. 確認
- 対象を「本人→ファミリー→グループ」と切り替え、見出しとAIの文章が変わることを確認します。
- ラッキーカラーの文字が読めることを確認します。
- テスト用プラン切替でグループ上限（1/3/10/30）を確認します。
- 上限の規則には自動テストを追加します。

## 技術メモ
- 新規テーブル `team_groups`（id, user_id, name, nickname, member_ids uuid[], created_at）を作り、本人のみRLSを設定します。上限はトリガーで `plan_memberships` と照合します（既存のメンバー上限と同じ方式）。ゲストは `onore-groups` に保存します。
- `team_members` に `nickname text default ''` を追加します（後方互換）。
- `profiles` に `goal text default ''`, `goal_preset text default ''`, `target_kind text default 'self'`, `target_id uuid null` を追加します。ゲストは `onore-focus` に保存します。
- `FocusProvider` で対象を一元管理します。home-reading と quick-essence のキャッシュキーに、対象と目的を含めます。相談・相性診断のコンテキストにも対象と目的を渡します。
- `plans.ts` に `groupLimit` を追加し、`plan-details.ts` の7言語の文言を更新します。
