# 出生宇宙創生図「出生地球軸・二焦点構図」再構築計画

## 最良の提案

**惑星を見栄えのために個別移動せず、出生瞬間の地球方向そのものを作品の構図軸にする**方法が最適です。

太陽を第一の焦点、出生地点が見える地球拡大像を第二の焦点とし、軌道上の実際の地球から拡大地球へ向かう方向を作品全体の大きな対角線にします。全惑星の相対角度・距離順位・軌道形状は維持したまま、太陽系全体へ一つの共通回転と共通縮尺だけを適用します。

これにより、どの生年月日でも「太陽系として正しい」ことと「一枚絵として重心が整っている」ことを両立します。

## 1. 出生地球を基準にした構図

- 出生瞬間の軌道上の地球ベクトルを、太陽から画面右下へ伸びる主対角線へ合わせます。
- 太陽は左上寄りの黄金比付近、出生地球の拡大像は右下寄りへ置き、二つの焦点の間に自然な視線の流れを作ります。
- 画面回転は全惑星・全軌道へ一括適用し、惑星同士の実際の角度関係は一切変えません。
- 出生日時が変われば構図も変わりますが、必ず同じ規則で決まる決定的な作品にします。

## 2. 距離感を壊さない自動フレーミング

- 現在の共通対数距離縮尺を維持し、内惑星と外惑星の距離順位を正確に保ちます。
- 8惑星・軌道・太陽の投影範囲を毎回計測し、上下左右の余白が最も安定する**一つの共通倍率**で画面へ収めます。
- 惑星ごとの位置補正、半径補正、軌道の変形は行いません。
- 地球拡大像の領域だけを先に確保し、太陽系全景との衝突を避けます。空いた領域は星雲・星座・干支の遠景に使います。

## 3. 「実配置」と「地球拡大像」を一枚へ統合

- 軌道上の小さな地球は実座標・実直径比のまま残します。
- そこから出生地球拡大像まで、直線ではなく細い星間塵と光粒の流れでつなぎます。
- 拡大地球は出生地を正面にし、出生時刻の自転角・地軸・昼夜境界を同じデータから描きます。
- 出生地点は総合カラーの宝石光として明確に示し、光霧が主対角線に沿って宇宙へ広がる表現にします。

## 4. 天体の見え方と画面の重心

- 惑星サイズは物理半径比と全惑星共通倍率を維持します。
- 木星・土星など大きな天体は構図上の副焦点として活かし、小惑星は精細な縁光と星粒で見失わないようにします。
- 前後関係は実3Dベクトルの奥行きを使い、遠景は霞、前景は輪郭と質感を強めます。
- 土星は球体と環を別々に描き、球体を扁平化せず、環外径の物理比も保持します。

## 5. 軌道線・星雲・星座・干支の整理

- 軌道線は計算済みの実軌道点列を維持し、手前側を明るく、奥側を霞ませる立体的な金泥線へ変更します。
- 7色の星雲は天体を覆わず、太陽―出生地球の対角線と画面の余白を導くように配置します。
- 太陽星座・月星座・干支は空いた遠景へ統合し、天体配置より前に出ない光量と密度に抑えます。
- ラベルは天体を動かさず、外周の安全領域へ引き出し線で整理します。黄経・AU・縮尺説明は維持します。

## 技術詳細

- 天文計算結果は変更せず、描画側に「出生地球ベクトルから求める共通画面回転」と「全軌道境界から求める共通フィット倍率」を追加します。
- 投影順序を `出生瞬間の3Dベクトル → 共通視点投影 → 共通対数距離圧縮 → 地球軸の共通回転 → 共通フィット → 画面座標` に統一します。
- 太陽系全景と軌道上の地球は同じ変換を共有し、拡大地球だけを明示的な別縮尺として扱います。
- 画面表示と2048×2048保存は、同じ構図計算・座標・描画順を共有します。
- 外部通信ゼロ、即時表示、決定性、VIP権限を維持します。

## 検証

- 複数年代・複数時刻で、全惑星の相対角度、距離順位、軌道上の位置、物理半径比が変わらないことを自動確認します。
- 共通回転後も太陽中心の相対配置が保存され、軌道上の地球と拡大地球の対応方向が一致することを確認します。
- 地球の出生地点、自転角、昼夜境界、地軸が出生日時・出生地データと一致することを確認します。
- 天体・拡大地球・ラベルの衝突を複数の出生データで確認し、惑星位置ではなく余白・ラベル配置だけで解消します。
- PC・スマートフォン・全画面・2048保存で同じ構図と画質になることを確認します。
