# アゴルメンの羅針盤 全面改修計画

## 仕上がり
- 指定の見出しと「アゴルメン相談室」「アゴルメン相性診断」「アート」の名称を、日本語表示と関連する案内で統一する。
- ロゴは羅針盤・宝石を鮮明に保ちながら、周囲だけを柔らかく背景へ溶け込ませる。
- 個人診断と相性診断に、入力済みの干支・星座・血液型・続柄・4層動物占いを、利用できる項目だけ自然に織り込む。血液型や続柄による性格の断定、独自モデルを公式鑑定と誤認させる表現は避ける。
- 「星々の引力と生命の原点」の直後に、妻アサミの夢の啓示、カタツムリの殻、黄金螺旋と自分軸を語るブランド文を加える。
- 個人診断を先に最後まで読める構成にし、「総合多層占術診断」を個人診断コンテンツの締めへ移動。その直後に「あなたの可能性を、もう一歩先へ」を置き、プラン詳細とテスト用切替へ迷わず進める。実決済・請求は行わない旨を明示する。
- 「アート」には、VIP以上で見られる「バースカラー曼陀羅アート」と、出生天体配置と黄金螺旋を使う別作品「出生宇宙創生図（コズミック・アルケミー）」を並べる。両作品の高解像度PNG保存と、シェアシール付き画像の端末共有に対応する。共有先への直接投稿は保証せず、非対応端末では保存を案内する。
- デザイン選択を指定の15種・累計2/4/7/10/15種に整理。無料の純白は白ベースで読みやすく、暗い陰影と神秘的なアクセントを持つ外観にする。ロック中のテーマも選択前に画面サンプルを見られ、実際に使うときだけプラン案内を表示する。

## 進め方
1. 名称と表示位置を整理し、既存の7言語表示で日本語の旧称が残らないよう関連文言を更新する。
2. 診断文の材料と表示順を調整し、利用できない相手の血液型・続柄などを推測しないことを確認する。
3. 既存の天体計算・色計算・画像保存を再利用しつつ、二作品を区別して制作し、VIP以上の表示・保存・共有制限を揃える。
4. テーマ15種の外観・見本・階層制限を整え、保存済みの旧テーマ選択は安全に新しいテーマへ対応づける。
5. モバイルとデスクトップで診断の読了→プラン案内、無料/各プランのテーマ解放、アートの画像保存・共有、ロゴの視認性を確認する。

## 技術上の扱い
- 既存の会員プラン判定とテスト専用プラン切替を共通の判定に使い、画面上の切替で実際の有料資格を付与しない。決済サービスは接続しない。
- 4層動物占いの本質以外は既存の独自参考モデルとして明示し、天体位置以外の色・螺旋・九星装飾も創作表現として区別する。
- 画像共有はブラウザの端末共有機能を使用する。Instagramストーリーズ、X、TikTokへの画像付き直接投稿を装わない。
