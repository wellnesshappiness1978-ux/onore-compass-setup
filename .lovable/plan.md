# VIP「出生宇宙創生図」全画面公転軌道・天体存在感アップ計画

## 目標
出生瞬間の正確な太陽中心黄経と8本の公転順を変えず、円形公転軌道を画面の主役として四辺近くまで拡大します。太陽と8惑星は、サイズ順位を守ったまま輪郭・表面・大気・環・光を磨き、遠目にも各天体を識別できる格調高い宇宙作品へ仕上げます。

## 現在の構成と調整方針
確認した現行作品では、公転軌道は画面幅の約63%に収まり、上部の出生地球拡大図、左右の詳細ラベル、下部の9天体実サイズ比較へ大きな領域を割り当てています。そのため、正確な8軌道は見える一方、作品全体に対する軌道と天体の視覚重量が控えめです。

今回は科学情報を削除せず、主従を再編します。

- **主役**：画面いっぱいに広がる太陽中心の8本の円形公転軌道
- **第2階層**：出生瞬間の位置にある太陽と8惑星
- **補助情報**：外周へ整理した名称・黄経・距離・半径
- **科学比較**：下端へ薄く統合する9天体実半径比
- **出生地球**：外周の一角へ置く別縮尺の精密インセット

## 1. 公転軌道を画面いっぱいへ
- 太陽中心を作品中央付近へ戻し、海王星軌道を安全余白ぎりぎりまで拡大します。
- 8軌道は同心真円を維持し、水星から海王星までの順序と代表軌道長半径に基づく共通対数間隔を変更しません。
- 外周軌道は四辺近くまで届かせ、内惑星軌道も太陽周囲で潰れないよう、単一の改良対数カーブで間隔を再調整します。
- 軌道線は単なる細線ではなく、金・白金の極細芯、淡い光層、微細な星粒を重ねます。地球軌道だけを過剰に強調せず、8本全体を一つの天体工芸として見せます。
- 軌道や天体が画面端で切れない安全範囲を、土星の環と各天体のオーラまで含めて計算します。

## 2. 太陽・惑星の存在感とサイズ感
- 配置図内の太陽と8惑星は、現行の実半径由来・順位非逆転のスマートスケールを保ちながら、全体を一段大きくします。
- 太陽は中心核、粒状光球、コロナ、炎の隆起、周辺光を多層化し、作品の明確な中心として強化します。
- 木星の縞と大赤斑、土星の球体と多層環、火星の地形、金星の雲、水星のクレーター、天王星・海王星の大気など、既存素材の固有特徴を鮮明に見せます。
- 土星は球体径と環外径を別々に扱い、扁平化させません。
- 各惑星に固有色の薄い大気縁光、反射光、微細な星粒を加えますが、均一な円形グローや安価なネオン表現は避けます。
- 惑星が軌道線に埋もれないよう、天体直下だけ軌道の光量を局所的に落とし、輪郭をくっきり保ちます。

## 3. 科学情報を外周へ再配置
- 左右の長い引き出し線を短くし、名称・黄経・瞬間距離AU・平均半径を最寄りの外周安全領域へ自動配置します。
- ラベルは天体、土星環、出生地球、9天体比較と重ならないレーンへ振り分けます。
- 配置図が視覚的に小さくならないよう、説明文は上端・下端の細い余白へ集約します。
- 「配置図の天体径は視認用」「下端の9天体比較は同一線形縮尺」という区別を7言語で維持します。

## 4. 実サイズ比較と出生地球インセット
- 太陽を含む9天体の実半径比較は削除せず、下端の細い一体型比較帯へ圧縮します。数値比と同一線形縮尺は変えません。
- 小さな惑星を都合よく拡大せず、基準線と名称で位置を示します。
- 出生地球の拡大図は外周の空き領域へ少し大きく配置し、自転角、昼夜境界、地軸、出生地点の総合カラー光を明瞭に保ちます。
- 軌道上の地球との対応線は一本の控えめな金光へ整理し、公転軌道の流れを遮らないようにします。

## 5. 芸術性の強化
- 7バースカラーは正確な色コードを維持し、公転軌道の背後に流れる星雲・輝線・光芒・星屑へ限定します。
- 軌道円の外側と軌道間に暗い静寂域を残し、天体と金属光が浮かぶ奥行きを作ります。
- 星座と干支は遠景の低コントラスト光彫刻として残し、軌道円や惑星を横切らない安全領域へ再配置します。
- 一律のぼかしではなく、天体表面の細部、近景の星粒、中景の軌道、遠景の星雲で解像感を段階化します。

## 6. 維持する条件
- 各惑星の出生瞬間の太陽中心黄経は変更しません。
- 軌道順は常に `水星 < 金星 < 地球 < 火星 < 木星 < 土星 < 天王星 < 海王星` を維持します。
- 中央配置図の天体サイズ順位と、9天体実半径比較の同一線形縮尺を維持します。
- 曼陀羅はStandard以上、出生宇宙創生図はVIP以上という権限分離を変更しません。
- 外部画像生成・外部通信を追加せず、即時表示、決定的再生成、全画面、共有、2048×2048 PNG保存を維持します。
- 1024表示と2048保存は同じ配置・描画関数を共有します。

## 技術詳細
- `cosmic-art.ts`で画面安全領域、拡大した共通軌道縮尺、改良対数間隔、視認用天体スケールを一元化します。
- `CosmicGenesisCanvas.tsx`で軌道の多層描画、惑星直下の局所コントラスト、天体表面・縁光、外周ラベル、地球インセット、下端サイズ比較の描画順を再構成します。
- 天文計算値やプロフィール入力処理には変更を加えません。

## 検証
- 複数の生年月日・時刻で、全惑星が正しい黄経角と対応軌道上にあることを自動検証します。
- 8軌道が公転順を保ち、海王星軌道が画面を大きく使いながら、天体・土星環・オーラを含めて切れないことを検証します。
- 太陽と惑星の視認用サイズ順位、9天体比較の実半径比、土星の球体・環比を検証します。
- PC、スマートフォン、全画面、2048保存で、軌道・天体・ラベル・出生地球・比較帯の重なりや欠けを確認します。
- 初回描画後に最低2回、軌道の太さ、天体の輪郭、ラベル密度、星雲の彩度、余白だけを磨く視覚調整を行います。
