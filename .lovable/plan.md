# 宝飾曼陀羅 中心ぴったり合わせ計画

## 調べて分かったこと
- 色・金線・花びら・羅針盤・宝石・背景の光は、すべて同じ座標系で描いていて、中心は(0,0)＝キャンバスのちょうど真ん中。宝石を下にずらす値もない。
- 一番下に敷いている油彩の下絵（1024×1024）を簡易計測したところ、明るい中心部が真ん中より約20px上にあった。そのため、正しく真ん中にある宝石が、下絵の羅針盤に比べて下にずれて見えている可能性が高い（まだ確定ではないので、最初に測り直す）。
- 画面表示と保存画像はどちらも、下絵と模様を同じ正方形にぴったり重ねている。上下の余白で押し下げられる作りにはなっていない。

## 手順
1. 下絵の羅針盤の中心（金の円と放射線の中心）を、明るさの重心だけでなく円の当てはめで1px単位まで測り直し、実際にどれだけずれているかを確定する。
2. 下絵を、ずれの分だけ反対方向に動かした新しい画像として保存し直す（はみ出した端は漆黒の宇宙で補う）。これで下絵の羅針盤の中心が真ん中(512,512)にそろう。
3. 模様側は(0,0)のまま変えない。宝石のグループに余計な位置ずらしを入れず、中心の固定を明記する。
4. 画面表示：下絵と模様は同じ正方形の枠いっぱいに重ねる。下に出る「数秘・主元素・カット」の表示は絵の上に重ねるだけなので、絵の位置には影響しない。
5. 保存画像（2048×2048）も同じ下絵と同じ模様で作り、ずれが出ないことを確かめる。

## 確認方法
- テスト：宝石の頂点の平均が(0,0)になること（6・8・12角とスターの全部）、どの層にも位置ずらしが入っていないこと、背景の光の中心が(0,0)であること。
- 実画面と2048保存画像で、下絵の羅針盤の中心と宝石の中心のずれを測り、1px以内になっていることを確かめる。

## 技術詳細
- 計測：Pythonで下絵を読み、中央の金色部分について、径を変えたリングの明るさの対称性が最大になる中心を探す。
- 下絵の補正：PILで(-dx,-dy)だけずらし、端は#05070Fで埋めて、`src/assets/mandala-base-vivid.jpg`を同じ名前で置き換える（読み込み側の変更は不要）。
- `MandalaCanvas.tsx`：宝石の`<g>`に`data-gem-center="0,0"`を付ける。表示と保存はどちらも`viewBox="-512 -512 1024 1024"`、`preserveAspectRatio xMidYMid`を使う。
- Playwrightで画面表示と保存画像の両方を撮って中心のずれを計算する。
