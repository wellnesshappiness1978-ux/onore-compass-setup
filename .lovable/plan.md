# VIP「出生宇宙創生図」アゴルメン最高級羅針盤・可読性 最終改修計画

## 目標
登録ユーザーの出生時刻・場所から再現する太陽中心の天体配置、出生地球・出生月、7つのバースカラー、星座・干支を守りながら、作品全体を「アゴルメンの羅針盤」の象徴にふさわしい一点物の高級工芸へ仕上げます。追加装飾を貼り足した印象ではなく、黄金羅針盤・オウムガイ・宇宙・科学情報が最初から一体で設計された、神秘的で複雑かつ読みやすい作品を完成基準にします。

## 現在確認できた状態
- 外周は72目盛り、12個の星座留め石、8方位、四隅の殻装飾を持ちますが、金属帯の幅が画面幅約3%に限られ、細密装飾が小さく見えます。
- 別枠の出生地球は右上、惑星は最外周軌道まで広がり、黄金枠が最後に前面描画されるため、天体が枠へ接近した位置では隠れて見えます。
- 各惑星の情報は左右端に細い文字だけで表示され、最小文字が小さく、淡い文字色と透過背景により金枠・星雲の上で読みづらくなっています。
- 画面表示と2048 PNGは同じ描画処理を共有しているため、今回の仕上げも両方へ同一に反映できます。

## 1. 黄金羅針盤を多層の高級金工へ再設計
- 軌道の外側を守りながら外周金属帯を内側へ広げ、古金・純金・白金・黒金の段差ある同心環、太い縁取り、縄目、粒金、象嵌、彫り、微細な摩耗、局所的な強い煌めきを重ねます。
- 72目盛り、8方位、12星座留め石を別々の装飾ではなく、同じ金工規則・光源・立体感で統一します。
- 主方位には厚い針状金具と宝飾留めを与え、「方角を示す羅針盤」として遠目でも読める骨格を作ります。
- バースカラーは金属を塗り替えず、七宝・宝石・細い反射光として正確な7色を使用します。

## 2. オウムガイの殻装飾を主役級の豪華さへ
- 四方の小さな渦を、大きく立体的なオウムガイの彫金レリーフへ作り直します。
- 黄金螺旋、扇状の隔壁、成長線、粒金、白金の稜線、7色の宝石留めを多層化し、近くでは殻、遠くでは羅針盤の守護紋章として見える二重表現にします。
- 装飾は外周金属帯のマスク内に厳密に収め、軌道線、惑星、出生月、文字へ侵入させません。
- 太陽を「内なる軸」、殻を「強い家」として呼応させ、アゴルメンの由来が説明文なしでも伝わる構成にします。

## 3. 地球・惑星と金枠の重なりを解消
- 惑星・土星環・出生地球・出生月それぞれの外形と光彩を含む安全領域を計算し、金枠へ近い天体は枠の内側へ視認用の微調整を行います。出生黄経そのものは変えません。
- 外周付近の天体は、金枠を一部だけ背後へ回す前後関係と、天体の縁光を金枠の手前に重ねる表現を使い分け、隠れず立体的に見せます。
- 右上の別枠出生地球は専用の宝飾台座と静寂域を設け、外枠・見出し・星雲と衝突しない位置と大きさへ整えます。
- 惑星の科学的な出生角度、公転順、軌道順、現在の表示倍率、月の地心方向は維持します。

## 4. 惑星・恒星の詳細情報を読みやすく再構成
- 左右の情報を、金枠と同化しない濃い黒曜石／濃紺の不透明度が高い銘板へ変更し、細い金縁と控えめな影で宇宙画へ馴染ませます。
- 惑星名を明確な見出し、黄経・AU・実半径・地球比を整列した詳細行として分け、現在より大きい文字と高コントラスト色を使用します。
- 引き出し線は天体から銘板まで重なりを避けて配線し、出生地球・出生月・太陽にも同じ視覚規則を適用します。
- 日本語を含む7言語で、長い文言は自動縮小だけに頼らず改行・行間・銘板幅を調整し、1024表示と2048保存の双方で読める大きさを確保します。
- 下端の実半径比較も名称と数値の色・文字サイズ・背景を揃え、金枠より前に明瞭に読めるようにします。

## 5. 神秘性と芸術性の最終統合
- 七彩星雲、天の川、星座光彫刻、守護干支、太陽光、惑星光彩を、天体・金枠・銘板の周囲だけ局所的に抑える静寂域で整理します。
- 金属の重さ、宇宙の奥行き、宝石の透明感、星雲の柔らかさを異なる質感で描き分け、単なる発光や装飾過多にしません。
- 画面中央から「太陽 → 惑星 → 出生地球と月 → 黄金羅針盤 → 殻紋章 → 科学情報」の順に自然に視線が巡る階層へ整えます。
- 同一プロフィールから必ず同じ作品を再現し、外部通信ゼロ・即時描画・VIP限定・7色無加工・ライブ表示と2048 PNGの同一性を維持します。

## 6. 検証と仕上げ
- 金枠内径が全軌道の外側にあり、殻装飾が金属帯外へ出ず、天体・月・情報文字を横切らないことを自動テストします。
- 複数の出生日時で、各天体と金枠・銘板の安全距離、出生黄経、公転順、月の方向、9天体実半径比較が維持されることを確認します。
- 全7言語で、惑星情報と下端比較に文字切れ・極小文字・低コントラストがないことを確認します。
- PC、スマートフォン、全画面、2048 PNG保存を実画面で確認し、金工の重厚感、殻の豪華さ、天体の前後関係、文字の可読性を最低2回の目視調整で仕上げます。
