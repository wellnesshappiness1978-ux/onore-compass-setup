# 占術レイヤー・バースカラー・地球暦のプラン連動アップデート

## 1. 本格風水学を主要分析手法に追加
- 15占術ガイドの「主要な分析手法と役割」に「本格風水学（本命卦・玄空飛星）」を追加します。
- 生年月日と性別から求めた本命卦の吉方位（生気・天医・延年・伏位）、部屋別のインテリア・色・植物、気の滞りを防ぐ工夫を、個別診断・AI相談室・今日のコンパスに組み込みます。
- 「住まいの方角」はプロフィールに任意の「玄関の向き（8方位）」として追加し、入力があれば相性のよい玄関向きかどうかを表示します。

## 2. 占術レイヤーを6タブに
- 姓名判断・数秘術・西洋占星術・四柱推命・動物占い・風水の6つをタップで切り替えられるようにします（スマホ2列・PC3列）。
- 各タブは専門用語を減らし、約100文字の「要点・本質・具体的なアドバイス」に書き換えます。
- 動物占いは本質キャラを表示します。表面・希望・隠れの3層は信頼できる算出表がないため、引き続き「表を提供いただければ追加」とし、作った結果は表示しません。

## 3. バースカラーのプラン別表示
- 6枚のカード：総合（メイン）・サブ・マネー・ラブ＆人脈・ヘルス・マインド。
- 無料：総合のみ表示し、残り5枚は「有料プランで開放」のロックを表示します。有料以上：6枚すべて表示します。
- 色はこれまでの1440色パレット（太陽の位置・出生時刻の分・出生地から決まる再現可能な計算）を使います。マネー・ラブ・ヘルスは同じパレットのずらし位置で決め、それぞれに小物・インテリアでの取り入れ方を添えます。
- 「cocolor.biz準拠」「周波数(Hz)」を名乗ることはしません。公式の対応表は手元になく、色を周波数として測った値でもないためです。公式表をいただければそれに置き換えます。

## 4. 地球暦のプラン別アクセス
- 今の「無料でも全部選べる」状態を直し、表示中のプランに合わせて正しく制限します。
  - 無料：今日の太陽・惑星の配置図と、基本の4フェーズ（種まき/育成/収穫/休息）の概要のみ。
  - 有料：365日の個人バイオリズム曲線（攻め時/守り時）と、Google・iPhoneカレンダーへの予定追加（追加前に内容を確認）。
  - VIP：8方位の吉方位ナビ、バイオリズムと連動した3D曼陀羅への導線。
  - ビジネス／ビジネスプレミアム：年間の経営リズムのガントチャート、契約・商談・立ち上げ・投資の「候補日」、登録メンバーのリズムを重ねた好調期・注意期アラートと具体的な対応例。
- 候補日は「成功確率が高い日」とは表示しません。リズムに基づく参考の候補日として表示します。

## 5. テスト用プラン切替との連動
- 開発用の切替（未ログインでも使えるもの）で、上記のカラー・地球暦・占術タブの制限がその場で切り替わることを確認します。
- 公開版で誰でも有料機能を開けるようにはしません（課金が未接続のため）。

## 技術メモ
- 判定はDashboardのプラン状態（devPlanOverride反映済み）を、`HelioCalendar`、`BirthColorGuide`、`SelfCoreCard`のレイヤーパネルにpropsで渡し、`plans.ts`に機能→最低プランの対応（birthColorsFull: standard, helioPersonal: standard, helioDirections: vip, helioBusiness: b2b）を追加。
- 風水タブは `feng-shui.ts` の `mingGua` / `annualFlyingStars` を使用。玄関の向きは `profiles` に `facing_direction text default ''` を追加。
- 個人365日曲線と組織の重ね合わせは `helio-phase.ts` を拡張した決まった計算（同じ入力なら同じ結果）。組織版は `team-analysis.ts` のメンバーを使用。
- AIへの指示（home-reading / consultation）に風水値とカラー6種を追加。
- Playwrightで無料→有料→VIP→ビジネスの切替と各ロックを確認。
