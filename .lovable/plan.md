# オノレコンパス：デザイン・クイック相性・AI相談室の改修計画

## 目指す体験
- テーマを選んだ瞬間、背景・文字・枠・書体まで一貫して切り替わり、一覧では各デザインの雰囲気を選ぶ前に見比べられる。
- クイック相性では、相手の基本情報だけでも読め、任意の詳細を入れるほど根拠のある比較項目が増える。
- AI相談室では本人と登録関係者を切り替え、誰について相談しているか明確な状態で回答を受けられる。

## 実装
1. **アプリデザイン**：選択状態と実際に適用されるテーマを一致させ、各テーマの背景・本文と見出しの書体・文字色・カード枠・ナビを整理する。現在の設定一覧は基本7種＋追加12種の計19種なので、追加12種だけでなく既存テーマも反映確認する。黒×金の基調を保ちながらテーマごとの色・光彩・幾何学・粒子をミニプレビューへ反映。上位プランのバッジとロック解除演出を付け、動きを控える設定では停止する。選択したテーマは再訪時も保持し、プラン変更で利用不可になれば安全なテーマへ戻す。
2. **クイック相性**：既存のお名前・生年月日・出生時間・出生地・関係性に、血液型ときょうだい順、必要な出生地の詳細を任意項目として追加。本人と相手の入力を検証し、既存の姓名画数・数秘・天体位置・四柱・動物・干支・参考バースカラー・本命卦計算を利用できる範囲で組み合わせる。結果は引き寄せ傾向、思考の相乗、衝突点と現実的な対処、色の補完を具体的な比較根拠とともに表示し、7言語の既存表示方式に沿わせる。入力が足りない要素は補完・断定せず「未算出」と明示。現在の端末単位の日次回数とプラン表示制限は維持する。
3. **AI相談室**：「出生・お名前データ」を「個人データ」に変更。本人・登録関係者を選ぶメニューを設け、対象者の切替で会話文脈を分離し、対象の氏名・生年月日など実際に保存された情報だけを相談リクエストへ渡す。本人との相性を尋ねた場合は双方の確定データから比較し、不足する出生時刻・出生地・氏名の区切りなどは推測しない。本人専用の非公開保存と日次回数制御は維持する。
4. **プレビュー確認**：開発用の最上部プラン切替で未ログインでも各プランのテーマ・相性結果・関係者の相談対象切替を操作できるようにする。テスト用の関係者情報は端末内の既存保存方法を利用し、公開環境の会員権限や保存可能人数は変更しない。画面幅別に全テーマの反映、詳細入力あり／なし、対象者切替後の回答、プラン変更時のロックを確認する。

## 既存データと表現上の境界
現状、相性診断の文章は主に生年月日の数値差で生成され、関係者の登録項目は氏名・生年月日・性別・血液型・役割・スキルです。出生時刻・出生地・姓と名の区切りは保存されていないため、登録関係者の相談では利用可能な層だけを出し、必要なら入力を促します。動物占いの追加3層は独自参考モデル、色と相性指標も参考情報として表示し、科学的性格判定・「魂」の実証・結果保証を主張しません。
