# 中心宝石を「総合カラーの油彩八角形ダイヤモンド」へ深化

## 目指す仕上がり
現在の中心宝石の大きさと、周囲へ溶け込む四運色・繊細な光の構成は保ちます。宝石そのものを、総合カラーを核にした端正な八角形のダイヤモンドへ描き直し、透明なCG宝石ではなく、熟練画家が細い筆で光と色を重ねた油彩細密画として輝かせます。

## 更新内容
1. **美しい八角形を明確にする**
   - 外周、クラウン、テーブル、パビリオンを同じ八角形構造で整え、中心から各頂点へ精密なカット面を構成します。
   - 黒い縁、円形の台座、円形模様は戻さず、宝石の輪郭は総合カラーの濃淡と反射光だけで浮かび上がらせます。

2. **総合カラーを主役にしたダイヤモンド表現**
   - 総合カラーの正確な色を宝石の核に使い、明部・中間色・深部へ同系色を重ねます。
   - 白い鏡面反射、淡い金光、わずかな虹色の屈折を細い面ごとに配し、総合カラーが失われない透明感と奥行きを作ります。

3. **油絵らしい繊細な筆致**
   - 宝石内部だけに微細な絵具の粒、筆筋、厚みの揺らぎを加え、均一なデジタル面をなくします。
   - 面の境界は鋭さを保ちながら、色の重なりには絵具特有の柔らかなムラを残し、手描きの宝石画として馴染ませます。

4. **上品な輝きへ整理する**
   - 宝石上のきらめきは、主役の白い反射と小さな補助光に整理し、八角形とカット面を隠さない配置にします。
   - 周囲の屈折光と7色のきらめきは維持し、宝石から自然に生まれた光として接続します。

## 確認
- 宝石が一目で端正な八角形ダイヤモンドに見える
- 宝石の主色がユーザーの総合カラーと一致する
- 黒い縁・円形台座・円形背面模様がない
- 油彩の筆触と宝石の精密なカットが両立している
- PC、スマートフォン、全画面、保存PNGで形・色・光が一致し、欠けや重なりがない
- 描画テストと画面確認を行い、最初の仕上がりを批判的に点検して必要な微調整を加える

## 技術メモ
- `MandalaCanvas.tsx` の宝石形状を、外周・クラウン・テーブル・パビリオンの多層八角形へ再構成します。
- 総合カラーを基準にした宝石専用グラデーション、油彩粒子・筆筋用フィルター、面ごとの反射を追加します。
- 宝石の爪留めは外し、色と光だけで埋め込まれた印象を作ります。
- テストへ八角形構造、総合カラー、油彩フィルター、円形・黒縁・爪留め不使用の検証を追加します。
