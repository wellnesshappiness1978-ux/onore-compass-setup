# 中心宝石を「星核のローズカット」へ再構築

## 目指す仕上がり
現在の金色が強い直線的な8面宝石を、曼陀羅全体の重厚な油彩・植物的な花弁・繊細な金泥に馴染む、手仕事の一点物へ作り直します。

おすすめは、総合カラーを主役にした**非対称のローズカット宝石**です。透明なガラス玉やアニメ的な金塊ではなく、天然石の微細な内包物、薄い色むら、手研磨の面揺らぎを持つ「星の核」のような佇まいにします。

## 更新内容
1. **形と大きさを整える**
   - 現在の規則的な8角形を廃止し、12〜16面の不均一なローズカットへ変更します。
   - 宝石は中心を支配しすぎない約20%縮小とし、周囲の紫・青・四運色の花弁と一体に見える比率へ整えます。
   - 黒い縁、円形台座、太い輪郭、目立つ爪留めは使いません。

2. **総合カラーを本来の主役にする**
   - 金色へ寄りすぎている面構成を改め、総合カラーそのものを宝石面の大部分へ残します。
   - 同系色の深部、乳白色の反射、淡い金泥の反射だけで奥行きを作り、別の宝石色に見えないようにします。
   - 中心には一点の強い白光ではなく、複数の小さな反射面が静かに瞬く上品な輝きを与えます。

3. **油彩作品へ馴染ませる**
   - 宝石内部へ細かな鉱物筋、顔料粒、微細なクラック、薄い光の層を決定的に生成します。
   - 面の境界を均一なCG線ではなく、手研磨の揺らぎと金泥の極細線で描きます。
   - 宝石から出る光は直線的な放射ではなく、隣接する花弁へ溶ける短い屈折光と反射色へ整理します。

4. **作品全体との調和**
   - 健康・恋愛・仕事・金運の色彩が宝石の背後から自然に覗き、中心へ視線を導く構成を維持します。
   - 既存の宇宙背景、殻の螺旋、油彩花弁、7色の多様なきらめきは変更しません。

## 品質確認
- 総合カラーが一目で宝石の主色として分かること
- 金塊、ボタン、アニメ調、円形台座に見えないこと
- 拡大時に天然石の内包物と手研磨面が読め、縮小時にも中心核として美しいこと
- PC・スマートフォン・全画面・保存PNGで構図と色が一致すること
- 同じ7色と再生成番号では同じ宝石になり、再生成時のみ細部が変わること
- 外部通信なし、表示待ちなし、既存の保存・共有動作を維持すること

## 技術詳細
- 中心宝石の多角形生成を、不均一な外周・中間面・小さな天面からなるローズカット構造へ置換します。
- 総合カラーから同系色の明暗のみを算出し、鉱物筋・内包物・反射面をローカルSVGフィルターと決定的シードで描画します。
- 宝石専用の検証を、形状、総合カラー保持、円形／黒縁／台座なし、決定性、保存一致まで更新します。
