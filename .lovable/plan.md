# 多言語・相性診断・関係者プロフィール全面更新

## 実装内容

### 1. 7言語の完全ローカライズ
- 日本語・英語・簡体字・繁体字・韓国語・スペイン語・フランス語を、機能別の翻訳辞書へ統一します。
- 固定文言、ボタン、入力欄、モーダル、エラー、読み上げ、共有画像、サポート・法務ページまで翻訳対象に含めます。
- 日本語／英語だけの分岐や英語への暗黙フォールバックを廃止し、選択言語を画面・共有物・AI出力へ一貫して反映します。
- 各言語で主要導線を実画面確認し、残存する日本語と不自然な表示崩れを機械検索と目視で確認します。

### 2. アゴルメン相性診断の3段階化
- 現在の4章構成を、次の3章へ再構成します。
  1. 各占術での相性ポイント
  2. 総合相性のお告げ
  3. 二人の注意点とアドバイス
- 算出済みの名前・生年月日・出生時刻・出生地・性別・血液型など、実際に入力された情報だけを組み合わせます。
- 専門用語や生の計算値は本文から除き、生活・仕事・家庭で現れやすい関係性と、具体的な会話・行動案へ翻訳します。
- 全7言語で各章を自然な文章として用意し、未入力情報を推測しない注意書きを維持します。

### 3. ロゴ背景の横線だけを除去
- 現行の最新ロゴ、パープル／ゴールドのオーラ、放射光、輝きは維持します。
- ロゴ背面の水平ライトストリークだけを対象に除去し、通常表示と待機表示の両方を確認します。

### 4. Standard以上の関係者プロフィールを詳細化
- 既存データを失わない形で、関係者に「よみがな、生年月日、出生時刻、時刻不明、出生地、性別、血液型、続柄、役職・関係性タイプ、スキル」を保存できるよう拡張します。
- 追加・編集・削除に対応し、既存の端末内プレビューデータも後方互換で読み込みます。
- 本人だけが閲覧・変更できる保護と、Standard 2名／VIP 5名／Business 30名／Premium 100名の既存上限を維持します。
- 詳細情報を相性マトリクス、接し方取扱説明書、連携アドバイスへ渡し、欠けている項目は補完・推測せず省略します。
- 無料プランや表示テストが実際の会員権限・保存上限を迂回しない構成を維持します。

## 技術詳細
- 関係者テーブルへ追加列を安全な既定値付きで追加し、既存の所有者限定アクセス制御と登録上限トリガーを保持します。
- 入力値は画面側とサーバー側の両方で検証し、長さ・日付・時刻・選択肢を制限します。
- 相性診断は既存の決定論的計算を土台にし、未検証の感情・運命・有料権利を断定しません。
- AIを使う詳細取扱説明書は既定モデルと既存の安全なサーバー経路を維持し、実リクエストで確認します。

## 確認
- 7言語それぞれでオンボーディング、7タブ、相性診断、設定、サポート・法務、共有表示を確認します。
- FreeとStandard以上で表示・保存・上限を確認し、既存関係者データの読み込みも検証します。
- デスクトップとスマートフォンで、3章診断、詳細フォーム、ロゴ演出、文字切れ・重なりを確認します。
- 関連計算テスト、保存処理、AI応答、最新ビルドを確認して完了とします。
