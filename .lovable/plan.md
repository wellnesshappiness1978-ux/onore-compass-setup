# 出生宇宙創生図・曼陀羅超越アート刷新計画

## 目指す完成像
出生宇宙創生図を「色の強いデジタル天球」から、観察するほど新しい発見がある一点物の幻想的写実絵画へ再構築します。天体そのものは実在感と固有性を最優先し、バースカラーは物体の塗色ではなく、宇宙空間に漂う星雲・輝線星雲・光芒だけに昇華します。細密さ、奥行き、素材感、焦点設計のすべてで現行の曼陀羅アートを上回る完成度を基準にします。

## 1. 八惑星を「個別の絵画作品」へ
- 現在の単純な球グラデーションと反復ストローク主体の表現を廃止し、各惑星専用の高精細表面テクスチャをアプリ内素材として制作します。
- 水星は衝突盆地と鉱物肌、金星は厚い硫酸雲、火星は峡谷・極冠・砂嵐、木星は乱流帯と大赤斑、土星は繊細な雲帯と多層環、天王星・海王星は流体雲と深い嵐を描き分けます。
- 球面への自然な回り込み、明暗境界、縁光、大気散乱、反射光、微細な油彩粒子を重ね、貼り付けた円ではなく空間に浮かぶ天体へ仕上げます。
- 地球は主役として、深い海、大陸、雲、薄い大気、オーロラ、海面反射を別層で描き、宝石感は残しながら実在感を大幅に高めます。

## 2. バースカラーの役割を宇宙現象へ限定
- 現在の強い惑星オーラと天体表面への色混合を撤去し、惑星固有色を守ります。
- 7色は加工せず、広域星雲、細い輝線星雲、奥行きの異なる光芒、星間塵の反射、土星環へのごく微かな環境光として使います。
- 7色すべてを保持しつつ、同時に均等発光させず、前景・中景・遠景へ分散して色の競合を抑えます。
- 星雲は円形グローの集合ではなく、流体状の輪郭、暗黒帯、発光縁、微細なガス繊維が連続する大きな流れとして構成します。

## 3. 複雑性と絵画鮮度の引き上げ
- 深宇宙背景を、暗黒帯・星形成領域・ダイヤモンドダスト・遠方銀河・星間雲が重なる高精細な新規マスター素材へ更新します。
- 描画を「遠景宇宙→星雲→星座／干支→軌道の余韻→天体→前景の光と塵」に分け、距離ごとに焦点、粒度、コントラストを変えます。
- 均等な星粒や規則的な線を避け、静かな領域と高密度な領域を対比させ、視線が地球から木星・土星、星座、守護像へ巡る構図に整えます。
- デジタル感の原因となる均一な輪郭、同型ブラシ、過剰なスクリーン発光を抑え、局所的な絵具厚、半透明の薄塗り、擦れ、微細な金粉を使い分けます。

## 4. 星座と干支を背景芸術として統合
- 太陽星座と月星座は大きさを維持しながら、線図ではなく星雲から立ち上がる光の彫刻として描きます。
- 干支守護像は単純な輪郭記号から、十二支ごとに姿勢・顔・装飾が読める半透明の金泥細密画へ深化します。
- いずれも惑星を遮らず、遠景の霞、金箔の剥落、星明かりを使って宇宙空間へ自然に沈ませます。

## 5. 曼陀羅を上回る品質基準
- 曼陀羅の強みである多層質感、細密金工、遠近の粒度差、中心の主役性を基準にし、宇宙作品ではさらに「惑星ごとの固有情報」と「広大な空間奥行き」を加えます。
- 100%表示だけでなく拡大時にも、惑星表面、星雲繊維、金泥、微細星が破綻しない密度で制作します。
- 初回描画と2048×2048保存は同じ共通レンダラーを使い、外部通信ゼロ、即時表示、同一プロフィールでの再現性を維持します。

## 技術詳細
- 高精細な宇宙背景と惑星別表面素材は制作時に生成・調整してアプリへ同梱し、利用時の画像生成や外部API呼び出しは行いません。
- `CosmicGenesisCanvas`を背景、発光ガス、星間塵、星座／守護像、天体表面、大気、環、前景光へ分割し、惑星ごとの専用ペインターを実装します。
- バースカラーは星雲系レイヤーへ集約し、惑星本体のパレットから除外します。出生時の8惑星黄経、サイズ順位、衝突回避、7色の正確な値、VIP権限は変更しません。
- 視覚回帰テスト用の描画属性と、惑星固有表面・7色保持・惑星への色混入防止・決定性・2048出力を確認するテストを追加します。

## 検証
- 同じ出生データで旧作・新作・曼陀羅を並べ、天体の実在感、細部密度、空間奥行き、色の品位を比較します。
- PC、スマートフォン、全画面、2048保存を実際に画像確認し、惑星の単調さ、円形グロー、色飽和、重なり、粗い輪郭を重点的に修正します。
- 初回レンダー後に最低2回の視覚QAと修正を行い、最終パスで新しい問題がないことを確認します。
- VIP閲覧・保存・共有、Standard以下のロック、8惑星の黄経とサイズ、七色、オフライン描画、再現性の自動テストを実行します。
