# 5大コア占術レイヤー 統合診断エンジン

## 目的
「あなたの特性 & 個別診断」と「AI相談室」の両方で、同じ計算結果（5レイヤー）を使い、レイヤー同士をクロス解析した、具体的で言い切る文章を出す。

## 1. 5レイヤーの計算（生年月日・出生時間・氏名から自動算出）

| レイヤー | 算出する値 | 状態 |
|---|---|---|
| 姓名判断 | 天格・人格・地格・外格・総格と吉凶。人格（主運）と総格（総運）から社会での軸・人間関係・生涯の強みを決める | 既存の画数表で算出済み。そのまま共通化 |
| 数秘術 | ライフパス・ディスティニー・ソウル・パーソナリティ数、個人年数、9年周期での今の位置、次の転機の年 | 新規追加：9年周期と転機の年（ピナクル） |
| 西洋占星術 | 太陽・月・水星・金星・火星〜冥王星の10天体の星座。出生時間がある場合はアセンダント | 新規：天文計算ライブラリで正確に算出（出生地がないため東京基準、時間不明なら月はずれる可能性ありと表示） |
| 四柱推命 | 年柱・月柱（節入り基準）・日柱・時柱、日干、通変星、十二運星、五行バランス（8文字の木火土金水の数） | 新規：月柱・時柱・通変星・十二運星・五行カウント |
| 動物占い | 60分類の本質キャラ、行動タイプ（目標指向型/状況対応型など） | 本質は算出可能。下記の注意を参照 |

算出できない値（出生時間なし、画数表にない漢字など）は「未算出」と表示し、推測値では埋めない。

## 2. クロス解析ルール（プログラム側で組み合わせを確定）
AIに任せず、組み合わせと「同じ／ずれ」の判定をプログラムで作ってからAIに渡す。
- 四柱推命の日干の五行 × 太陽星座のエレメント（火地風水）：同じ傾向か、反対か
- 姓名判断の人格の五行 × 数秘のソウル数：外に見せる顔と魂の欲求が同じか、ずれているか
- 動物占いの本質 × 月星座：素の自分と無意識の感情
- 表の顔（人格・太陽・通変星） と 本音・潜在能力（ソウル数・月・十二運星） を一覧表にまとめて対比させる

## 3. 文章の品質ルール
- 「〜な面もあります」「人それぞれ」など、ぼかす言い方と誰にでも当てはまる文を禁止
- 1文ごとに根拠となる算出値を1つ以上つなげる（例：「人格21画・日干庚」）
- 結論から言い切る。ただし職業・健康・未来の出来事は断定しない
- 伝統的な占いの見方として書き、科学的に確かめた結果とは書かない（既存ルールを維持）

## 4. 画面
- 特性カードに「5レイヤー」表示枠を追加：各レイヤーの主要な値をバッジで表示し、クロス解析の「表の顔／本音」の対比を1ブロックで表示
- 章の構成を5レイヤー＋クロス解析＋最大の武器に更新（7言語の見出し）
- AI相談室は同じ計算結果を裏で使う（画面の変更なし）

## 確認していただきたい点
- **4層動物占い**：「本質・表面・希望・隠れ」の4キャラの出し方は、個性心理學の独自の方法で公開されていません。勝手に作ると、実在しない結果を本物のように見せてしまいます。そのため本質キャラ（公開されている60分類）のみを算出し、残り3層は「未算出」とする予定です。正式な対応表をお持ちであれば、それを使って4層すべてを実装できます。
- 出生地を入力していないため、西洋占星術は東京基準で計算します。

## 技術メモ
- 新規 `src/lib/ai/core-layers.ts`：5レイヤーとクロス判定の純粋関数（決まった入力なら結果は毎回同じ）。`divination-params.ts` と `five-elements.ts` から共通化
- 天体計算：`astronomy-engine`（純JS、Worker対応）を追加
- 月柱は太陽黄経315°（立春）と30°ごとの節入り、時柱は五鼠遁で算出。十二運星は日干×各支の標準表
- `home-reading.functions.ts` と `consultation.server.ts` のプロンプトに、構造化したレイヤー値とクロス表を渡す。モデルは `openai/gpt-6-astra` のまま
- 既知の日付（例：1995-04-08 10:30）で四柱・天体の値を単体テストし、Playwrightでカード表示と相談の回答を確認
