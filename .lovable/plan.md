# VIP「出生宇宙創生図」黄金天球儀アート深化計画

## 目標
添付画像はそのまま複製・埋め込みせず、**古代天球儀の重厚な金工、中央太陽の聖性、深い宇宙青、渦巻く星雲、整然とした銘板**を品質基準として取り入れる。現在の科学配置を守りながら、眺めて所有したくなる「出生瞬間の一点物の天球儀」に仕上げる。

## 現在確認できた点
- 現行作品は、中央太陽、8本の円形公転軌道、出生瞬間の太陽中心黄経、軌道上の出生地球、右上の出生地球拡大図、下端の9天体実半径比較をすでに備えている。
- 7色星雲、左上の天の川、星座・干支、天体周囲の静寂域も現在の共通描画に統合され、ライブ表示と2048保存は同じ描画関数を使っている。
- 参考画像との差は、外周の工芸的な額縁、中心から外周までを統一する金工意匠、背景の大きな渦、情報銘板の物質感、全体の「収蔵品」らしい重厚さにある。

## 1. 黄金天球儀の外周意匠
- 海王星軌道の外側に、細い金泥線・彫金模様・宝石留め・目盛りを重ねた円形アストロラーベ枠を追加する。
- 枠は公転軌道や惑星を圧迫しない薄い多層リングとし、角部は深宇宙を残して正方形画面の抜けを保つ。
- 装飾は固定シードで生成し、ライブ表示と2048保存で形が変わらないようにする。

## 2. 中央太陽と8惑星の宝飾的深化
- 太陽を金属レリーフのような多層光球へ深化し、粒状表面、炎の隆起、彫金状コロナ、短い光芒を重ねる。
- 惑星画像の科学的固有色と模様は維持し、球面陰影、細いリムライト、局所的な星光、柔らかな個別オーラで立体感を高める。
- 土星は球体と環の読み分けを強め、軌道上の出生地球は現在の出生時向き・昼夜方向・大気縁光を保持する。
- 直近の約16%拡大と内側軌道の安全間隔を維持し、天体同士や黄金枠と接触させない。

## 3. 渦巻く七彩宇宙背景
- 参考画像の中央渦を、7つの正確なバースカラーによる多層星雲として太陽の背後へ追加する。
- ベタな虹色や強いネオンにはせず、半透明のガス、輝線、暗黒帯、微細星粒を重ね、主役順は総合・健康・恋愛・仕事・金運のままにする。
- 現在の左上の天の川、遠景の星座・干支、天体周囲の静寂域を維持し、惑星表面やラベルの可読性を損なわない。
- 背景は「遠景星空 → 天の川 → 七彩渦状星雲 → 星座・干支 → 軌道 → 天体」の奥行きで一枚の作品へ統合する。

## 4. 科学情報を工芸的な銘板へ整理
- 外周ラベルは小さな金属銘板風へ統一し、名称・黄経・AU・実半径比を現在の左右レーンで整然と配置する。
- 上部の配置説明、右上の出生地球拡大図、下端の9天体実半径比較を同じ金工意匠で結び、貼り付けたUIではなく作品の一部に見せる。
- 文字量と7言語内容は増やさず、長い言語でも枠外や天体へ重ならない寸法を確保する。

## 5. 維持する科学・機能条件
- 太陽中心、出生瞬間の8惑星黄経、公転順、代表軌道長半径の対数間隔を変更しない。
- 中央配置図の単調視認スケールと、下端9天体比較の同一線形実半径比を変更しない。
- 出生地球の自転角・昼夜境界・地軸・出生地点の総合カラー光を維持する。
- 曼陀羅はStandard以上、出生宇宙創生図はVIP以上という管理を維持する。
- 外部通信ゼロ、即時・決定的描画、全画面、共有、2048×2048 PNG保存を維持する。

## 6. テストと目視検証
- 既存の天体順序、黄経角、軌道安全域、天体サイズ順、9天体線形比率、7色保持、VIP制限の全テストを通す。
- 黄金枠追加後も、海王星軌道・全惑星・出生地球拡大図・外周銘板・下端比較帯が安全領域内に収まる検証を追加する。
- PC、スマートフォン、全画面、2048保存を同じ検証プロフィールで確認する。
- 初回描画後に最低2回、金属感、渦状星雲の彩度、文字の余白、天体の見やすさを目視調整し、参考画像の重厚さへ近づけつつ科学情報を埋もれさせない。
