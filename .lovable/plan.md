# 出生宇宙創生図「実データ基準」再構築計画

## 方針
装飾用に固定している惑星サイズ・軌道半径・楕円率を廃止し、**出生瞬間の天文データを先に計算し、その結果だけを共通ルールで画面へ縮尺変換**します。

実寸と実距離を同じ縮尺にすると惑星がほぼ見えないため、次の二つを明確に分けます。

- **配置・軌道**：実際の太陽中心座標と軌道形状を基準にし、距離のみ全惑星共通の対数縮尺で圧縮
- **惑星サイズ**：実直径比を保持したまま、全惑星へ同じ拡大倍率を適用
- 手前の地球拡大図は、太陽系全景とは別縮尺の「同じ地球の拡大像」として光流で結ぶ

これにより、木星と水星などの大きさの関係、内惑星と外惑星の距離感、出生瞬間の方向関係を創作配置ではなくデータで説明できる絵にします。

## 1. 惑星の大きさを実直径比へ変更
- 現在の鑑賞用サイズ値を、NASA等で一般に使われる平均半径相当の固定物理値へ置き換えます。
- 水星を1とした各惑星の直径比を描画でも維持し、木星＞土星＞天王星・海王星＞地球・金星＞火星＞水星の実際の関係を崩しません。
- 全惑星には同じ表示倍率をかけ、特定の惑星だけを都合よく拡大しません。
- 土星は本体の球径と環の外径を別データとして扱い、画像全体を引き伸ばさず、球体と環の比率を現実に沿わせます。
- 太陽系全景の地球と、手前の出生地球拡大図には「同一天体・別縮尺」と分かる表現を残します。

## 2. 出生瞬間の実座標から配置を決定
- 各惑星の出生瞬間の太陽中心3次元ベクトルを取得し、黄道面へ共通投影します。
- 現在の固定軌道半径と装飾用の縦つぶし率を廃止します。
- 方位角は実ベクトルから算出し、全惑星へ一つの画面回転だけを適用します。惑星ごとの位置調整は行いません。
- 太陽からの実距離（AU）は共通の対数縮尺へ変換し、内惑星と外惑星を一画面に収めつつ距離順位を正確に保ちます。
- 前後関係は実ベクトルの奥行き成分で決め、装飾用のサイン波による深度を廃止します。

## 3. 軌道線を実軌道ベースへ変更
- 各惑星について、出生日時を基準に天文計算した軌道上の複数サンプル点から軌道線を生成します。
- 離心率による軌道の偏り、惑星ごとの軌道規模、投影後の形を保持し、均等間隔の装飾楕円を廃止します。
- 軌道線にも惑星位置と同じ距離圧縮・投影・回転を適用し、惑星が必ず自分の軌道上に載るようにします。
- 線は細い金泥と星屑で作品世界へ馴染ませますが、形状そのものは装飾で変更しません。
- 地球軌道だけを適度に強調し、拡大地球への対応を読み取れるようにします。

## 4. 正確さが伝わる表示
- 各惑星ラベルに出生瞬間の太陽中心黄経と太陽距離（AU）を表示します。
- 作品下部に「位置・角度＝出生瞬間の実計算／距離＝共通対数縮尺／天体径＝実直径比の共通拡大」と短く明記します。
- 惑星やラベルが重なる場合は、天体位置を動かさずラベルだけを安全領域へ逃がします。
- 星雲、星座、干支、バースカラーは背景演出として維持し、天文情報の形や位置を変えないレイヤーに限定します。

## 5. 地球拡大図との整合
- 太陽系全景の軌道上の地球は実座標・実直径比で描きます。
- 手前の地球は出生地確認用の拡大図として維持し、出生時刻の昼夜境界、地軸、出生地の球面位置を同じデータから描きます。
- 軌道上の地球から拡大地球へ伸びる光流は、対応関係のみを示し、軌道や天体位置を隠さない細さへ調整します。

## 技術詳細
- 天文計算層へ太陽中心3Dベクトル、実距離AU、平均半径、土星環外径、軌道サンプルを追加します。
- 描画層には全惑星共通の `投影 → 距離圧縮 → 画面回転 → 座標変換` を一つだけ設けます。
- 距離圧縮は単調増加関数とし、距離順位と同一方向を保証します。惑星半径は物理半径比へ一律倍率をかけ、位置計算から独立させます。
- 画面表示と2048×2048保存は、同じ天文データ・縮尺関数・軌道点列を共有します。
- 外部通信は追加せず、現在のローカル天文計算のみで即時・決定的に生成します。

## 検証
- 複数年代について、全惑星の描画角度が太陽中心ベクトルの角度と一致することを自動確認します。
- 描画距離の順位が実距離AUの順位と一致し、各惑星が計算した軌道線上に載ることを確認します。
- 惑星径の比率が物理半径比と一致し、土星本体が平たく変形しないことを確認します。
- PC・スマートフォン・全画面・2048保存で、天体や軌道を移動させずにラベルだけが衝突回避できることを確認します。
- Standardの曼陀羅／VIPの出生宇宙創生図という権限分離、外部通信ゼロ、ライブ表示と保存画像の一致を維持します。
