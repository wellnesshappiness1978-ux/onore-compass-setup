# 出生宇宙創生図「太陽中心・実配置」再構築計画

## 方針

作品の中心を**出生瞬間の太陽**へ戻し、8惑星を実際の太陽中心3D座標から配置します。見栄えのための惑星ごとの移動やサイズ調整は行いません。

ただし、太陽系の実距離と実直径を完全に同一縮尺にすると惑星が画面上で見えなくなります。そのため、次の二つを明確に分けます。

- **位置と距離感**：実座標・実軌道を基準に、全惑星共通の対数距離縮尺で一画面へ収める
- **天体サイズ**：実半径比を完全に保持し、太陽以外の全惑星へ一つの共通表示倍率だけを適用する

これにより、出生瞬間の配置を読み取れる太陽系図と、作品として鑑賞できる存在感を両立します。

## 1. 太陽を作品の絶対中心へ

- 太陽を画面中央へ固定し、全軌道と全惑星をその周囲へ配置します。
- 現在の「太陽を左上、拡大地球を右下」に置く二焦点構図は廃止します。
- 作品を見た瞬間に、太陽中心の出生時太陽系であることが分かる同心的な構図へ戻します。
- 画面全体に必要な回転は一度だけ適用し、惑星同士の実際の相対角度は変えません。

## 2. 出生瞬間の実配置と距離感

- 8惑星は出生日時から計算した太陽中心3Dベクトルをそのまま共通投影します。
- 黄経、前後関係、太陽からの距離順位、各惑星が載る軌道形状を維持します。
- 水星から海王星までを見せるため、距離だけに単調な共通対数縮尺を適用します。
- 惑星ごとの位置補正、均等配置、装飾用の軌道変形は行いません。

## 3. 実際の惑星サイズ比

- 水星・金星・地球・火星・木星・土星・天王星・海王星は、平均半径の物理比を厳密に保持します。
- 全惑星へ一つの共通表示倍率を適用し、特定の惑星だけを大きくしません。
- 木星＞土星＞天王星＞海王星＞地球＞金星＞火星＞水星の関係が一目で伝わる描画にします。
- 土星は球体半径と環外径を別の物理値として描き、球体を平たく変形させません。
- 太陽は惑星と完全同率にすると画面を覆うため、主図内では「中心天体」として別縮尺であることを表示上明確にします。

## 4. 出生地球の見せ方

- 軌道上の地球は、他惑星と同じ実半径比・共通倍率で描きます。
- 出生地点、自転角、昼夜境界、地軸を確認できる地球拡大像は、太陽系主図と競合しない外周の円形細部図として分離します。
- 拡大像には「地球拡大」と分かる控えめな表記を付け、実寸表示と誤認させません。
- 出生地点は総合カラーの宝石光で示し、軌道上の地球との対応は細い星間塵の流れだけで結びます。

## 5. 軌道・背景・情報表示

- 計算済みの実軌道点列を使い、手前は鮮明、奥は霞む立体的な軌道線にします。
- 星雲、7つのバースカラー、星座、干支は背景へ抑え、太陽系の実配置を隠さない密度にします。
- 各惑星の黄経・距離AU・名称は外周の安全領域へ引き出し線で整理し、天体自体は動かしません。
- 画面内に「位置＝出生瞬間の実計算／距離＝共通対数縮尺／惑星径＝実半径比の共通拡大／太陽・地球細部図＝別縮尺」と明記します。

## 技術詳細

- 描画変換を `出生瞬間の太陽中心3Dベクトル → 共通視点投影 → 共通対数距離圧縮 → 共通画面回転 → 太陽中心フィット` に統一します。
- 太陽中心を常にキャンバス中央へ固定し、全軌道境界から一つの共通フィット倍率を算出します。
- 惑星半径は物理半径×一律倍率のみで求め、位置計算から完全に分離します。
- ライブ表示と2048×2048保存は、同じ計算結果・描画順・素材を共有します。
- VIP限定、外部通信ゼロ、即時表示、決定性、全画面・共有機能を維持します。

## 検証

- 複数年代・時刻で、太陽が中央に固定され、全惑星の相対角度・前後関係・距離順位が計算値と一致することを確認します。
- 全惑星の描画半径比が物理半径比と一致し、個別補正がないことを自動確認します。
- 各惑星が自身の計算軌道上にあり、土星本体と環の比率が保たれることを確認します。
- 出生地点、自転角、昼夜境界、地軸が保存プロフィールと一致することを確認します。
- PC・スマートフォン・全画面・2048保存で、同じ太陽中心構図と天文データが使われることを確認します。
