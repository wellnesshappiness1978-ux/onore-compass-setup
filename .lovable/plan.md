# バースカラー曼陀羅「八角形ダイヤモンド」品質向上計画

## 目指す仕上がり

中心を、総合カラーそのものが深く澄んで輝く、美しい八角形のダイヤモンドへ刷新します。現在の天然石風ローズカットではなく、対称性と透明感を備えた高級宝飾品らしいカットにし、周囲のバースカラーは輪郭のある色帯ではなく、中心から外側へ溶け合いながら徐々に移り変わる幻想的な色彩として仕上げます。

## 更新内容

1. **総合カラーの八角形ダイヤモンド**
   - 外形を端正な八角形に統一し、正面から見た宝石らしいテーブル面・クラウン面・下層の反射面を組みます。
   - 総合カラーを主色として保ち、同系色の深い反射、白金色の鋭いハイライト、透明な内部反射を重ねます。
   - 現在の不規則な輪郭、天然石の内包物、金色に寄りすぎる面構成を取り除き、精密で透明感のあるダイヤモンド表現へ変更します。
   - 黒い縁、円形の台座、爪留めは使わず、宝石そのものが光を放つ構成を維持します。

2. **宝石の立体感と品質を向上**
   - 八角形の外周から中央テーブル面へ複数段のファセットを配置し、面ごとに光の角度と明暗を細かく変えます。
   - 強い白色反射は数か所に限定し、細い稜線、内部の色反射、控えめな虹色分散光で実物の宝石らしい奥行きを作ります。
   - 宝石周辺の光は直線的なアニメ表現に戻さず、短く繊細な屈折光として曼陀羅へ馴染ませます。

3. **境界のないバースカラー・グラデーション**
   - 現在の各色の円形帯と、中心周辺の色別花弁を、隣接色が広く重なる連続グラデーションへ再構成します。
   - 健康・恋愛・仕事・金運の順序は保ちながら、境界をぼかし、次の色へ自然に溶け込む透明な色面と油彩の筆致を重ねます。
   - サブカラーと心のカラーは独立した帯にせず、主要4色をつなぐ偏光や細部のニュアンスとして控えめに混ぜます。
   - 7色の正確なカラー値は保持し、混色部分だけを滑らかな中間色として見せます。

4. **既存アートとの調和**
   - 現在の宇宙背景、星々、オウムガイ／殻の黄金螺旋、金細工、鮮やかなきらめきは維持します。
   - 新しい宝石と色彩グラデーションが細密な外周へ自然につながるよう、中心付近の金線と光量だけを整理します。
   - 外部画像サービスは使わず、即時表示・オフライン動作・同一カラーでの決定的な作品生成を維持します。

## 確認項目

- 中心宝石が明確な八角形で、総合カラーが主色として一目で分かること
- 宝石が平面図形や金色のメダルではなく、透明感と立体感のある高級ダイヤモンドに見えること
- 黒縁、円形台座、爪留め、不自然な内包物が残っていないこと
- 中心を取り巻く7色に硬い境界線や分離した色帯がなく、徐々に美しく変化すること
- 健康・恋愛・仕事・金運の順序と、補助的なサブカラー／心カラーが保たれること
- PC、スマートフォン、全画面、保存画像で色・形・光が一致し、欠けや重なりがないこと
- 外部通信なし、同じ7色で同じ作品、再生成時のみ装飾配置が変わること

## 技術的な対応

- 中心宝石を8頂点の外形、内側8頂点、中央テーブル面からなる多段ファセット構造へ置換します。
- 総合カラーを基準にした複数の透明グラデーション、鏡面反射、色分散用の局所光を追加します。
- 既存の色別円環を、隣接色を含む連続グラデーションと広いぼかしを持つ重なりへ変更します。
- 描画テストを八角形カット、8方向ファセット、総合カラー保持、色順、境界のぼかし、外部通信なし、保存一致の検証へ更新します。
