# プラン構造・関係者枠・ビジネス組織コンサル機能の実装

## 前提（変えない点）
- 課金・実際の会員資格はまだありません。プランは「表示テスト用の切替」（ログイン中はビジネス会員テスト）で判定し、画面に「開発テスト・課金未実装」と表示します。
- 占術スコア・相性・バイオリズムは生年月日などから作る**参考値**で、正式な15占術鑑定とは表示しません。

## 1. プランと登録上限
| プラン | 関係者枠 | 解放機能 |
|---|---|---|
| 無料 ¥0 | 0人（本人のみ） | 基本 |
| スタンダード ¥333/月 | 2人 | 関係者登録 |
| VIP ¥777/月 | 5人 | 曼陀羅アート全解放・チーム同時診断 |
| ビジネス ¥9,800〜 | 30人 | 組織・プロジェクトコンサル全機能 |
| ビジネスプレミアム ¥8,888/月（新設） | 100人 | 100名フル機能・優先AI生成 |

- 会員プラン表・プラン切替に「ビジネスプレミアム」を追加（7言語）。
- 上限を超えて追加しようとすると「上位プランへの切り替え」ダイアログを表示。

## 2. 関係者（メンバー）名簿
- 名前・生年月日・性別・血液型・役職/得意職種・スキルタグを登録。
- ログイン中は本人専用のデータとして保存（他人からは見えない）。未ログイン時は端末内のみ。

## 3. 新しい「チーム」画面（マイページから入る、機能ごとにタブ）
1. **チーム同時診断＆立ち位置マトリクス**（VIP 5名 / ビジネス30名 / プレミアム100名まで選択）: 総合バランススコア、2軸マトリクス上に各メンバーの立ち位置（ムードメーカー・参謀・実行部隊・調整役など）、シナジーの線と衝突ポイント一覧。
2. **AI最適人員選抜＆ランキング**（ビジネス以上）: 企画・イベントの目的と希望人数を入力 → AIが最適メンバーと人数を提案、スコア順ランキングと組み合わせの特徴・評価・注意点。手動差し替え→再評価ボタン。
3. **タレント・組織名簿カタログ**（ビジネス以上）: カード型一覧（得意職種・スキル・思考パターン・響く言葉・今日のバイオリズム）、職種/スキル/タイプでフィルター検索。
4. **ビジネス自動アラートカレンダー**（ビジネス以上）: 目的（商談・契約・採用面接・1on1）を選ぶと月間カレンダーに最適日/注意日のカラーバッジとスコア、日別攻略アドバイス、Googleカレンダー追加リンクとApple用（.ics）ダウンロード。
5. **組織バランス＆欠如タイプ検出**（ビジネス以上）: 五行・タイプ分布グラフ、「チェック役不在」「アイデアマン過多」などの指摘と次に採用すべきターゲット像。
6. **1on1マネジメント・トリセツ**（ビジネス以上）: メンバーを選んでワンタップで「やる気が出る褒め方」「NG指示」「モチベーション低下時の対処法」をAI生成。

- 未解放の機能はロック表示＋アップグレード案内。
- プレミアムは「優先AI生成」をラベル表示のみ（実際の優先処理なし）。

## 技術詳細
- DB: `team_members` テーブル（user_id, name, birth_date, gender, blood_type, role, skills text[], created_at）、GRANT＋RLS（本人のみ CRUD）。上限はUIで判定（課金未実装のためサーバー強制はしない旨をAGENTS.mdに記録）。
- `src/lib/design-modes.ts` の `Plan` に `b2b-premium` を追加、`src/lib/plans.ts` に上限・機能フラグを集約。
- 決定論的スコア: `src/lib/team-analysis.ts`（ライフパス・日干の五行・バースカラーからタイプ/相性/日別スコア算出）。
- AI: `src/lib/ai/team-ai.functions.ts`（createServerFn + Lovable AI、選抜・1on1トリセツを構造化出力、参考値である旨をプロンプトに明記）。
- UI: `src/components/team/*` に6タブ、SettingsPanelから開く。7言語コピー（ja/en 完全、他は en フォールバックを避け主要文言を翻訳）。
- 検証: 390/1280pxでPlaywright、上限ダイアログ、各タブ表示、ビルド確認。
